What-If Analysis

Adjust feature inputs and get predicted GENREP CPM, PM CPM, and Total CPM instantly.

Field definitions
total_miles: planned/expected total miles for this scenario.
rail_share: fraction of miles on rail. Example 0.90 = 90% rail, 10% highway.
pm_orders_per_1k_mi: PM order frequency per 1,000 miles.
genrep_orders_per_1k_mi: GENREP order frequency per 1,000 miles.
reactive_pm_share: share of PM done in mixed (repair+PM) context, 0 to 1.
pm_delay_mean_days: average PM timing delay in days (positive = late, negative = early).
pm_delay_pos_rate: fraction of PM cycles that are late beyond threshold.
pm_delay_neg_rate: fraction of PM cycles that are early beyond threshold.
pm_order_count: expected PM order count for the period/profile.
consignee: customer/consignee profile context.

Pipeline Steps

What scripts/refresh.py does once the project team runs it. Typical runtime: ~10–15 minutes.

  1. 1
    Validate data files exist — confirms all required files are at their expected paths.
  2. 2
    Feature engineering (build_trip_features_v3.py) — reads raw data, builds 199-column trip-level feature CSV → data/training/trip_features_v3.csv.
  3. 3
    Model training (build_risk_engine.py) — calibrated XGBoost on temporal train/test split (Jan–Sep / Oct–Dec) → data/risk_engine/*.
  4. 4
    Webapp export (export_webapp.py) — converts model artifacts to webapp-compatible JSON → webapp/data/*.
  5. 5
    Repair pattern analysis (repair_pattern_analysis.py) → webapp/data/repair_patterns.json.
  6. 6
    Validation & smoke test — model loads and scores a sample trip; AUC ≥ 0.70 expected.
